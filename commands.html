Package Mgmt [ Click to inspect ]

apt update && apt upgrade

Refreshes local package lists and upgrades all installed packages to their latest secure versions.

SYNTAX:
sudo apt update && sudo apt upgrade -y
DETAILS:

Crucial routine maintenance command for Debian systems. `update` fetches package metadata from repositories, while `upgrade` safely applies updates without removing existing packages.

Package Mgmt [ Click to inspect ]

apt install <package>

Downloads and installs new software packages along with all required dependencies.

SYNTAX:
sudo apt install nginx
DETAILS:

Debian's primary package management tool. It automatically resolves dependency trees from configured APT software repositories.

System & Services [ Click to inspect ]

systemctl <action> <service>

Controls and inspects the systemd system and service manager.

SYNTAX:
sudo systemctl restart nginx
sudo systemctl enable --now ssh
DETAILS:

Used to start, stop, restart, check status (`status`), or configure automatic startup on boot (`enable` / `disable`) for system daemons.

System & Services [ Click to inspect ]

journalctl

Queries and displays logs generated by systemd-journald, including kernel and service logs.

SYNTAX:
journalctl -u nginx -e --no-pager
DETAILS:

Essential for troubleshooting errors. The `-u` flag filters logs by service unit, `-e` jumps to the end of the logs, and `-f` follows live output.

Networking [ Click to inspect ]

ufw (Uncomplicated Firewall)

Manages netfilter firewall rules with an intuitive interface for server security.

SYNTAX:
sudo ufw allow 22/tcp
sudo ufw enable
sudo ufw status verbose
DETAILS:

Standard Debian firewall manager. Always ensure SSH access (`allow 22`) is permitted before enabling the firewall to avoid locking yourself out.

System & Services [ Click to inspect ]

htop

Interactive, color-coded process viewer and system monitor.

SYNTAX:
htop
DETAILS:

An improved successor to `top`. Allows you to sort processes by CPU/Memory usage, search for PIDs, and kill misbehaving processes directly with mouse or keyboard navigation.

Files & Disk [ Click to inspect ]

df -h & du -sh

Inspects disk space allocation and directory storage consumption.

SYNTAX:
df -h
du -sh /var/log/* | sort -hr
DETAILS:

`df -h` shows available partition space in human-readable units. `du -sh` summarizes folder sizes to help track down what is consuming your disk space.

Files & Disk [ Click to inspect ]

find <path> -name

Searches for files and directories across your file system based on name, size, or modification date.

SYNTAX:
find /etc -name "*.conf" -type f
DETAILS:

A powerful search utility. Filters can be chained, such as finding files modified in the last 7 days (`-mtime -7`) or files larger than 100MB (`-size +100M`).

Files & Disk [ Click to inspect ]

tar -czvf / -xzvf

Creates and extracts compressed tape archive files (tarballs).

SYNTAX:
tar -czvf backup.tar.gz /var/www/html/
tar -xzvf backup.tar.gz -C /destination/
DETAILS:

`c` = create, `x` = extract, `z` = gzip compression, `v` = verbose progress, `f` = filename. Essential for system backups.

Files & Disk [ Click to inspect ]

chmod & chown

Modifies file access permissions and user/group ownership.

SYNTAX:
sudo chmod 755 script.sh
sudo chown -R www-data:www-data /var/www/html
DETAILS:

`chmod` sets read/write/execute permissions (e.g., 755 or +x). `chown` alters file ownership recursively (`-R`) to specific system users or groups.

Networking [ Click to inspect ]

ip a & ss -tulpn

Inspects network interface configurations and active socket/port listeners.

SYNTAX:
ip a
sudo ss -tulpn
DETAILS:

`ip a` replaces legacy `ifconfig` to check IP addresses. `ss -tulpn` lists all listening TCP/UDP ports along with the process ID (PID) using them.

Text & Search [ Click to inspect ]

grep & awk

Searches text patterns and extracts or transforms data streams.

SYNTAX:
cat /etc/passwd | grep -i debian
ps aux | awk '{print $1, $2}'
DETAILS:

`grep` searches files or pipes for regex matching patterns. `awk` is a powerful text-processing programming language ideal for extracting specific columns and tabular data.
