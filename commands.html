Core Command & Config Matrix

An interactive high-performance reference guide listing essential commands, system controllers, and configuration files tailored for FreeBSD 15.1.

pkg
Command

FreeBSD's primary binary package manager. In FreeBSD 15.1, it powers both standard third-party ports and modern packaged base system layouts, handling updates, installations, and dependency tracking.

pkg update && pkg upgrade
sysrc
Command

Safely inspects or alters variables inside /etc/rc.conf without manual text file editing. It handles syntax verification and updates keys cleanly on the fly.

sysrc nginx_enable="YES" sshd_enable="YES"
service
Command

The standard control utility used to start, stop, restart, or check the operational status of rc.d system daemons and installed application services.

service pf status && service netif restart
zfs / zpool
Command

Manages enterprise ZFS storage arrays. zpool manages physical pools of drives, while zfs manages datasets, compression, cloning, and instant snapshot creation.

zpool status && zfs list -r zroot
bhyve
Command

FreeBSD’s native hypervisor enabling robust, production-grade virtual machine isolation with near-native execution speeds leveraging Intel VT-x and AMD SVM extensions.

bhyve -c 2 -m 4G -s 0,hostbridge -s 3,virtio-net,tap0 vm01
pfctl
Command

Manages the Packet Filter (PF) firewall. Used to load rule files, verify syntax cleanly without activating, flush active state tables, and enable or disable packet inspection.

pfctl -nf /etc/pf.conf && pfctl -e
jexec
Command

Allows administrators to enter or run management commands within an active FreeBSD jail container instance using its unique JID or jail name.

jexec web_jail_id tcsh
freebsd-update
Command

Official utility for checking, downloading, and applying binary security patches and point releases to the host FreeBSD operating system kernel and core utilities.

freebsd-update fetch && freebsd-update install
/etc/rc.conf
Config

The central initialization text file. Configures system hostname, networking interfaces, routing preferences, local firewall states, and global daemon activation keys.

hostname="bsd15.local"
ifconfig_em0="DHCP"
sshd_enable="YES"
/boot/loader.conf
Config

Processed during early boot phase prior to mounting filesystems. Declares loadable kernel modules, hardware settings, and scheduler preferences (e.g. kern.sched.name).

kern.sched.name="ULE"
zfs_load="YES"
aesni_load="YES"
/etc/sysctl.conf
Config

Defines persistent kernel configuration variables modified dynamically or loaded at startup to optimize network buffering, security hardening, and memory management.

net.inet.ip.forwarding=1
security.bsd.stack_guard_page=1
/etc/pf.conf
Config

The primary configuration file for PF firewall macros, tables, translation options (NAT/RDR), and inbound/outbound security filtering rulesets.

block all
pass in proto tcp from any to any port { 22, 80, 443 }
/etc/fstab
Config

Maps static block devices, swap allocations, and secondary UFS or external file mounts. (Note: Root ZFS datasets mount automatically via ZFS properties instead).

/dev/ada0p3.eli none swap sw 0 0
/etc/resolv.conf
Config

Specifies IP addresses of upstream DNS name servers and search suffixes used by the system resolver library to translate domain names.

nameserver 1.1.1.1
nameserver 8.8.8.8
pkg/repos/FreeBSD.conf
Config

Controls package repository URLs, signature enforcement policies, mirror selection, and quarterly vs. latest upgrade channels for the package subsystem.

FreeBSD: { url: "pkg+http://pkg.FreeBSD.org/${ABI}/quarterly", enabled: yes }
