VI COMMAND REFERENCE

System Access Protocol: Master All Modes
Normal Mode Default
  • EscEnter Normal mode (from any mode)
  • h / j / k / lMove left, down, up, right
  • w / bMove forward / backward by word
  • 0 / $Jump to start / end of line
  • gg / GJump to first / last line of file
  • xDelete character under cursor
  • dw / ddDelete word / delete entire line
  • yy / pYank (copy) line / Paste after cursor
  • u / Ctrl + rUndo / Redo last change
  • rReplace single character
  • /text / nSearch text forward / Next match
Insert Mode Editing
  • i / a / oEnter Insert mode (various positions)
  • Esc / Ctrl+cExit Insert mode (return to Normal)
  • iInsert text before cursor
  • IInsert text at start of line
  • aAppend text after cursor
  • AAppend text at end of line
  • oOpen a new line below current line
  • OOpen a new line above current line
Visual Mode Selection
  • v / V / ^vEnter Visual mode (Char / Line / Block)
  • EscExit Visual mode (return to Normal)
  • vEnter Visual mode (characterwise)
  • VEnter Visual Line mode (linewise)
  • Ctrl + vEnter Visual Block mode
  • d / xDelete selected text
  • yYank (copy) selected text
  • > / <Indent right / Outdent left selection
  • ~Toggle case of selected text
Command-Line Mode Ex Mode
  • :Enter Command-line mode (from Normal)
  • Enter / EscExecute / Cancel & exit to Normal
  • :wSave (write) file to disk
  • :q / :q!Quit / Quit without saving (force)
  • :wq or :xSave and quit
  • :e filenameOpen file for editing
  • :%s/old/gGlobal search and replace
  • :set nuShow line numbers
  • :set nonuHide line numbers
  • :nJump directly to line number n
