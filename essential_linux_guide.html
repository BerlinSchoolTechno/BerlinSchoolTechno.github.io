🚀 Applications, AI & Desktop Tools

Ollama Local AI

Ollama is a free, open-source application licensed under MIT that allows you to run large language models (LLMs) locally on your own computer, eliminating cloud service fees or per-token charges.

  • Installation: curl -fsSL https://ollama.com/install.sh | sh
  • Remove Models: ollama list then ollama rm [modelname]

Automatically Deleting Ollama Chat History

Ollama keeps a history of your chats by default in ~/.ollama/history. Typing /set nohistory in the CLI only disables logging for the current session.

To automatically delete the history file immediately after exit, run Ollama via a script:

#!/bin/bash
clear
ollama run llama3.1:8b
rm ~/.ollama/history
exit 0

Speech Note

Speech Note is a free, open-source, and privacy-focused app available for Linux and Sailfish OS. It allows users to take, read, and translate notes offline without an internet connection by offering speech-to-text, text-to-speech, and machine translation.

Upscayl

Upscayl is a free and open-source AI image upscaler desktop application. It enables you to enlarge images without losing quality, operating locally with no hidden costs or subscription fees.

Open-Meteo

Open-Meteo provides a free weather API for non-commercial, personal use without requiring registration or an API key. It serves as the default data service in the free Cinnamon "Weather" panel applet.

Markdown Cheat Sheet

Markdown is a lightweight, open-source markup language for formatting documents.

  • Basic Syntax: Headings (#), Bold (**), Italic (*), Blockquotes (>), Lists, Code, Rules (---), Links, Images. Supported universally.
  • Extended Syntax: Tables, Fenced Code Blocks, Footnotes, Strikethrough, Task Lists, Emoji, Highlights, Subscript/Superscript.

mp3gain

Normalize volume across multiple audio files without quality degradation:

sudo apt install mp3gain
mp3gain *.MP3 *.mp3

Prevent Google Login Prompts in Chrome

To block identity service popups in Google Chrome:

  1. Navigate to chrome://settings/content/federatedIdentityApi in the address bar.
  2. Set Default behavior to Block sign-in prompts from identity services.

What Are AAE Files?

AAE files are XML sidecar files used by the Apple Photos app to track modifications made to photos. They store edit data separately so the original photo remains untouched and edits can be undone anytime.

⚡ IceWM Installation & Configuration

Debian Base & Desktop Utilities Setup

Install core Xorg and desktop utilities on Debian Bullseye base:

# Base Xorg Install
su -
apt install xserver-xorg-video-all xserver-xorg-core xinit

# Desktop Utilities
apt install lightdm pnmixer pavucontrol pulseaudio alsa-utils gsimplecal lxterminal mousepad atril firefox-esr lxappearance synaptic sudo xscreensaver xarchiver picom pcmanfm lightdm-gtk-greeter-settings lzip

Compiling & Installing IceWM 3.3.4

Compile IceWM 3.3.4 from source on Debian:

wget https://ice-wm.org/scripts/os-depends.sh
sudo bash -x ./os-depends.sh

# Download, compile and install
wget https://github.com/ice-wm/icewm/releases/download/3.3.4/icewm-3.3.4.tar.lz
tar -x --lzip -vpf icewm-3.3.4.tar.lz
cd icewm-3.3.4
./configure --prefix=/usr
make
sudo make install

IceWM Startup Script Configuration

Create user startup file at ~/.icewm/startup:

#!/bin/bash
pcmanfm --desktop --profile icewm-session.desktop &
picom -bcf &
icesound -i ALSA & play /home/user/.icewm/sounds/startup.wav
(sleep 1s && pnmixer) &
(sleep 1s && /usr/lib/notification-daemon/notification-daemon) &
(sleep 1s && /usr/lib/policykit-1-gnome/polkit-gnome-authentication-agent-1) &
(sleep 1s && xscreensaver -no-splash) &

Make executable: chmod +x ~/.icewm/startup

Panel Tray Applets & Audio Setup

  • Clock Applet: Set panel clock in ~/.icewm/preferences to launch gsimplecal on left click.
  • Volume Control: Right-click pnmixer tray icon > Preferences > Behavior > Set volume command to pavucontrol.
  • Toolbar Icons: Add application launchers and .xpm icons to ~/.icewm/toolbar.

IceWM Dynamic Menu Generation

IceWM uses icewm-menu-fdo to generate menus dynamically. Add to ~/.icewm/menu:

includeprog icewm-menu-fdo --no-sep-others --seps

IceWM Themes & Visual Appearance

Place icon and theme directories in ~/.icons and ~/.themes. Configure GTK widget styles and icon sets using lxappearance.

🕒 Clock, Date & Time Settings

IceWM Clock Preferences & Presets

Config location: ~/.icewm/preferences

ClockCommand="gsimplecal"
TimeFormat="%I:%M %p"
  • Full Date/Time: %A, %B %d, %Y: %I:%M %p
  • 12-Hour Time: %I:%M %p

LightDM Clock & Time Zone

Configure LightDM Greeter clock format:

sudo lightdm-gtk-greeter-settings

Set clock format to %c under Panel tab.

Set System Time Zone:

sudo timedatectl set-timezone America/New_York

Dual-Boot Hardware Clock Sync

Synchronize hardware clock when dual-booting with Windows:

# Force local time RTC for Windows compatibility
timedatectl set-local-rtc 1 --adjust-system-clock

# Revert to UTC standard
timedatectl set-local-rtc 0 --adjust-system-clock

Common strftime Format Reference

CodeDescription
%A / %aFull / Abbreviated weekday name
%B / %bFull / Abbreviated month name
%d / %YDay (01-31) / 4-digit Year
%I / %H12-Hour / 24-Hour format
%M / %pMinute / AM or PM

📦 Package & System Management

Configuring & Upgrading Fedora

Enable RPM Fusion Repositories:

sudo dnf install https://download1.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm
sudo dnf install https://download1.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm

# Install multimedia plugins
sudo dnf group install multimedia

Disable Multiarch & Flatpak Install

Purge 32-bit i386 architecture:

sudo apt purge .*:i386
sudo dpkg --remove-architecture i386

Install Flatpak on Debian:

sudo apt install flatpak gnome-software-plugin-flatpak
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

Remove Ollama from Fedora

Cleanly remove Ollama and models from Fedora system:

ollama rm "model-name"
sudo systemctl stop ollama
sudo systemctl disable ollama
sudo rm /etc/systemd/system/ollama.service
sudo rm $(which ollama)
sudo rm -r /usr/share/ollama
sudo userdel ollama
sudo groupdel ollama

update-alternatives & Hostname

Configure default applications:

update-alternatives --get-selections
sudo update-alternatives --config x-www-browser

Change System Hostname:

sudo nano /etc/hostname
sudo nano /etc/hosts

🌐 Networking & Remote Access

Static IP Configuration (Debian 13)

Edit /etc/network/interfaces:

auto eth0
iface eth0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 8.8.4.4

Restart networking: sudo systemctl restart networking

Restart Interface & Firewall (UFW)

Request new DHCP lease:

sudo ifconfig eno1 down && sudo ifconfig eno1 up

Configure Firewall:

sudo apt install ufw
sudo ufw enable
sudo ufw status verbose

X11 Forwarding & PuTTY

Connect with X11 Forwarding:

ssh -X user@192.168.0.129

PuTTY Copy/Paste: Right-click pastes clipboard contents directly into the session. Shift+Insert performs the same action.

Monitoring Open Ports & Services

# List all listening TCP/UDP ports
sudo ss -tulpn

# Find process running on a specific port
sudo lsof -i :80

💾 Storage, Drives & File Systems

Change Drive Ownership & Permissions

Grant folder/drive ownership permissions:

sudo chown -R user:user /media/user/drive-uuid/

Grant read/write permissions:

sudo chmod ugo+wx /mnt/storage-drive/

SSD TRIM Configuration

Run TRIM manually or enable background weekly timer:

sudo fstrim -v /
sudo systemctl enable fstrim.timer
sudo systemctl start fstrim.timer

USB Drive Image Creation (dd)

Create image from drive:

sudo dd if=/dev/sdc of=~/thumbdrive.img bs=4M; sync

Restore image to USB drive:

sudo dd if=~/thumbdrive.img of=/dev/sdc bs=4M; sync

fstab Mount Settings & Usage

Get partition UUID using blkid. Example /etc/fstab entry:

UUID=b7a839e3-82a1... /mnt/storage auto nosuid,nodev,nofail,x-gvfs-show 0 0

Check disk space usage:

df -h
du -sh /path/to/folder

📦 Virtualization & Emulation

Fix VirtualBox vboxdrv Error

Load VirtualBox driver kernel module:

sudo modprobe vboxdrv

GNOME Boxes VM Backup

Backup VM disk images located in ~/.local/share/gnome-boxes/images/. Copy the image file to external storage and copy back to restore.

VirtualBox Guest Additions

sudo apt install build-essential linux-headers-$(uname -r) -y

sudo usermod -aG vboxsf user

⚙️ Boot, Kernel & System Administration

Fix Intel Graphics Screen Flicker

In Fedora 41, edit /etc/default/grub:

GRUB_CMDLINE_LINUX="i915.enable_psr=0 intel_idle.max_cstate=2 rhgb quiet"

Update GRUB config:

sudo grub2-mkconfig -o /boot/grub2/grub.cfg

User & Group Management

Remove user from group and delete group:

sudo gpasswd -d user vboxusers
sudo groupdel vboxusers

Clean unwanted EFI folders in /boot/efi/EFI using rm -r.

Hardware Info & Resource Monitoring

sudo apt install inxi

Resource monitoring commands:

htop
free -h
sudo journalctl -xe
